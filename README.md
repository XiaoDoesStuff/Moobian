# Moobian Breakdown
## Moobian Building Blocks
Moobian is built using:
- Debian Live-Build
- Debian 13 (Trixie) as a base
- GNOME desktop environment

## Moobian Alpha-1 (Holstein White).
Moobian is still in early stages of being made. Moobain Alpha-1, codename Holstein White is missing a lot.
- Debian branding is still heavily present in the operating system
- Some major drivers are missing, such as Wi-Fi
- Overall Polish is quite rough

## Moobian Theme
Moobian is cow themed from boot to desktop to terminal
- Grub has a cow-themed font and cow background
- GNOME's background is cow themed
- Fastfetch configured with a cow ASCII art.
More branding is planned.

## Future of Moobian
I plan to work on Moobian until I either get bored or complete Moobian to my liking.
